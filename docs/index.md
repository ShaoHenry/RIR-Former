# RIR-Former

Official evaluation code and dataset for our accepted ICASSP 2026 paper.

## Links

- GitHub repository: https://github.com/ShaoHenry/RIR-Former
- Evaluation script: https://github.com/ShaoHenry/RIR-Former/blob/main/eval_rirformer.py
- Dataset and checkpoints: see the GitHub README
- IEEE Xplore paper link: https://ieeexplore.ieee.org/document/11462487
- arXiv paper link: https://arxiv.org/abs/2602.01861
- DOI: 10.1109/ICASSP55912.2026.11462487

## Description

RIR-Former is the official implementation and dataset release for our ICASSP 2026 paper on room impulse response reconstruction.
